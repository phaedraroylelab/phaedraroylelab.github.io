# Phaedra Royle Lab Website

This repository contains the source code for the [Phaedra Royle Lab website](https://phaedraroylelab.ca/) — a research lab at the Université de Montréal focused on language development, speech disorders, and language processing in children and adults.

🧪 The website is designed to present the lab’s research, team members, publications, and projects in a clear and accessible way.

🔄 It supports updates without requiring a full rebuild, making content maintenance easy and efficient.

This project is maintained as a side collaboration by Kilian DECLERCQ.
